Per account · 50% Fable / 50% Opus · Opus includes all non-Fable models

Calculation

Each account has two allocations, each equal to half its weekly capacity. Opus usage is total weekly usage minus Fable usage, measured in the same units. The displayed percentages divide each model group's usage by its allocation. Numbers can exceed 100%; bars stop at 100%.

Every calculation stays within one account. Subscription remaining counts that account's shared allowance once. It does not add the two displayed allocation remainders. No usage, capacity, or remaining allowance is combined across accounts.

This prototype uses comparable sample capacity units, not tokens or API dollars. Live readings require verified model attribution, conversion and matching reset windows. A missing split stays unknown for that account only. No provider requests or routing changes.
