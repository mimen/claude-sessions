Calculation

Each account has two allocations, each equal to half its weekly capacity. Opus usage is total weekly usage minus Fable usage, measured in the same units. The displayed percentages divide each model group's usage by its allocation. Numbers can exceed 100%; bars stop at 100%.

The summary adds usage and capacity before calculating percentages. Subscription remaining counts the shared allowance once. It does not add the two displayed allocation remainders.

This prototype uses comparable sample capacity units, not tokens or API dollars. Live readings require verified model attribution, conversion and matching reset windows. A missing split stays unknown. No provider requests or routing changes.
