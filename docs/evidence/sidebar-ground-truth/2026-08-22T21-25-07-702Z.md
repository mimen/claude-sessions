## Spot-checks only you can run

The scripts prove the sources agree with each other and with disk. Three things 
only a human at the keyboard can verify:

1. **Tab count.** Count your open cmux tabs/windows by eye. The sweep says this run saw 14. Off by more than one you just opened/closed mid-run means the surface-tree tracking is wrong.
2. **The waiting flip.** Send any agent a task that ends needing your input. Its sidebar pill should flip to *needs input* within ~3 seconds. Run this sweep right after; agent-activity should show agreement, not a lagging derived label.
3. **Click-through.** Pick any live row in the sidebar and click it. The tab that gains focus must contain that exact session — not a twin, not a dead pane. This is the one check that validates identity resolution end to end, because only you know which session you meant.

If all three feel right but the sidebar still reads stale to you, the drift is in delivery/redraw (classes C/D), not in the tracked state — say so and we chase the revision pipeline instead of the data.
